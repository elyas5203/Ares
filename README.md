# دستیار هوش مصنوعی فروشگاه تحریرچی

این پروژه برای ساخت یک دستیار هوش مصنوعی برای فروشگاه آنلاین لوازم تحریر "تحریرچی" است. این دستیار به مدیریت فروشگاه، انجام کارهای روزمره و ارائه مشاوره در زمینه دیجیتال مارکتینگ کمک خواهد کرد.

## مراحل پیاده‌سازی

پروژه در چند مرحله اصلی انجام خواهد شد:

1.  **راه‌اندازی محیط توسعه:** نصب ابزارها و کتابخانه‌های مورد نیاز.
2.  **ایجاد ربات تلگرام:** ساخت یک ربات تلگرام برای تعامل با دستیار.
3.  **اتصال به Ollama:** اتصال ربات به مدل زبان Llama 3.
4.  **افزودن محصول به سایت وردپرسی:** امکان افزودن خودکار محصولات به سایت.
5.  **ایجاد داشبورد مدیریتی:** یک پنل وب برای مدیریت دستیار.
6.  **تحلیل رقبا و ارائه پیشنهادات:** قابلیت‌های پیشرفته برای تحلیل بازار.

---

## مرحله ۱: راه‌اندازی محیط توسعه

در این مرحله، کامپیوتر خود را برای شروع کدنویسی آماده می‌کنیم.

### ۱.۱: ساخت پوشه پروژه

یک پوشه (Directory) در کامپیوتر خود برای این پروژه ایجاد کنید. برای مثال، می‌توانید نام آن را `tahrirchi-ai-assistant` بگذارید. تمام فایل‌های پروژه در این پوشه قرار خواهند گرفت.

### ۱.۲: ایجاد محیط مجازی پایتون (Virtual Environment)

استفاده از محیط مجازی به ما کمک می‌کند تا کتابخانه‌های پایتونِ این پروژه را از سایر پروژه‌ها جدا نگه داریم.

- ترمینال (یا Command Prompt در ویندوز) را باز کنید.
- با دستور `cd` وارد پوشه‌ای که در مرحله قبل ساختید، شوید:
  ```bash
  cd path/to/tahrirchi-ai-assistant
  ```
- دستور زیر را برای ایجاد محیط مجازی وارد کنید:
  ```bash
  python -m venv venv
  ```

### ۱.۳: فعال‌سازی محیط مجازی

- **در ویندوز:**
  ```bash
  .\venv\Scripts\activate
  ```
- **در مک یا لینوکس:**
  ```bash
  source venv/bin/activate
  ```
بعد از اجرای این دستور، باید در ابتدای خط فرمان خود عبارت `(venv)` را ببینید. این یعنی محیط مجازی فعال شده است.

### ۱.۴: نصب کتابخانه‌های مورد نیاز

دستور زیر را در ترمینال وارد کنید تا کتابخانه‌هایی که برای شروع نیاز داریم نصب شوند:

```bash
pip install python-telegram-bot requests ollama
```

- `python-telegram-bot`: برای ساخت و مدیریت ربات تلگرام.
- `requests`: برای ارسال درخواست به سایت وردپرسی شما.
- `ollama`: برای ارتباط با مدل هوش مصنوعی Llama 3.

با انجام این مراحل، محیط توسعه شما آماده است و می‌توانیم به مرحله بعد، یعنی ساخت ربات تلگرام، برویم.

## راهنمای حل مشکلات

### مشکل اتصال به Ollama

اگر با خطای اتصال به Ollama مواجه شدید، به احتمال زیاد فایروال ویندوز شما از اتصال ربات به سرویس Ollama جلوگیری می‌کند. برای حل این مشکل، شما باید یک قانون جدید در فایروال ویندوز برای اجازه دادن به اتصالات ورودی به پورت `11434` اضافه کنید.

**مراحل اضافه کردن قانون جدید در فایروال ویندوز:**

1.  **باز کردن Windows Defender Firewall:**
    *   کلید `Windows` را فشار دهید و عبارت `Windows Defender Firewall` را تایپ کنید.
    *   روی `Windows Defender Firewall with Advanced Security` کلیک کنید.

2.  **ایجاد قانون ورودی جدید (Inbound Rule):**
    *   در پنل سمت چپ، روی `Inbound Rules` کلیک کنید.
    *   در پنل سمت راست، روی `New Rule` کلیک کنید.

3.  **انتخاب نوع قانون:**
    *   `Port` را انتخاب کرده و روی `Next` کلیک کنید.

4.  **مشخص کردن پروتکل و پورت:**
    *   `TCP` را انتخاب کنید.
    *   `Specific local ports` را انتخاب کرده و در کادر مربوطه، عدد `11434` را وارد کنید.
    *   روی `Next` کلیک کنید.

5.  **مشخص کردن اقدام:**
    *   `Allow the connection` را انتخاب کرده و روی `Next` کلیک کنید.

6.  **انتخاب پروفایل:**
    *   مطمئن شوید که هر سه گزینه `Domain`, `Private`, و `Public` انتخاب شده‌اند.
    *   روی `Next` کلیک کنید.

7.  **نام‌گذاری قانون:**
    *   یک نام برای قانون خود انتخاب کنید، برای مثال `Ollama Access`.
    *   روی `Finish` کلیک کنید.

پس از انجام این مراحل، ربات شما باید بتواند به سرویس Ollama متصل شود.

### مشکل اتصال به اینستاگرام

برای اینکه ربات شما بتواند به اینستاگرام متصل شود، تحلیل رقبا را انجام دهد و پست بگذارد، شما باید حساب کاربری اینستاگرام خود را به یک حساب کاربری تجاری (Business Account) تبدیل کرده و آن را به یک صفحه فیسبوک متصل کنید. سپس باید یک برنامه در پلتفرم توسعه دهندگان فیسبوک ایجاد کرده و از طریق آن به API اینستاگرام دسترسی پیدا کنید.

**مرحله ۱: تبدیل حساب کاربری اینستاگرام به حساب کاربری تجاری**

1.  **وارد پروفایل خود شوید:** برنامه اینستاگرام را باز کرده و به صفحه پروفایل خود بروید.
2.  **وارد تنظیمات شوید:** روی سه خط در گوشه بالا سمت راست ضربه بزنید و `Settings` را انتخاب کنید.
3.  **به بخش Account بروید:** روی `Account` ضربه بزنید.
4.  **تغییر به حساب کاربری حرفه‌ای:** به پایین صفحه بروید و روی `Switch to Professional Account` ضربه بزنید.
5.  **مراحل را دنبال کنید:** مراحل را دنبال کرده و گزینه‌هایی که به بهترین شکل کسب و کار شما را توصیف می‌کنند، انتخاب کنید. در نهایت، `Business` را به عنوان نوع حساب کاربری خود انتخاب کنید.

**مرحله ۲: اتصال حساب کاربری اینستاگرام به صفحه فیسبوک**

1.  **وارد تنظیمات شوید:** در همان بخش `Account` در تنظیمات اینستاگرام، روی `Sharing to Other Apps` ضربه بزنید.
2.  **فیسبوک را انتخاب کنید:** `Facebook` را انتخاب کرده و وارد حساب کاربری فیسبوک خود شوید.
3.  **یک صفحه فیسبوک را انتخاب کنید:** یک صفحه فیسبوک برای اتصال به حساب کاربری اینستاگرام خود انتخاب کنید. اگر صفحه‌ای ندارید، می‌توانید یک صفحه جدید ایجاد کنید.

پس از انجام این مراحل، حساب کاربری اینستاگرام شما به یک حساب کاربری تجاری تبدیل شده و به یک صفحه فیسبوک متصل شده است. در مرحله بعد، ما یک برنامه در پلتفرم توسعه دهندگان فیسبوک ایجاد خواهیم کرد.

**مرحله ۳: ایجاد برنامه در پلتفرم توسعه دهندگان فیسبوک**

1.  **وارد پلتفرم توسعه دهندگان فیسبوک شوید:**
    *   به آدرس [https://developers.facebook.com/](https://developers.facebook.com/) بروید و با حساب کاربری فیسبوک خود وارد شوید.

2.  **یک برنامه جدید ایجاد کنید:**
    *   روی `My Apps` در گوشه بالا سمت راست کلیک کرده و `Create App` را انتخاب کنید.
    *   `Business` را به عنوان نوع برنامه انتخاب کرده و روی `Next` کلیک کنید.
    *   یک نام برای برنامه خود انتخاب کنید، برای مثال `Tahrirchi Shop Assistant`.
    *   آدرس ایمیل خود را وارد کرده و روی `Create App` کلیک کنید.

3.  **ابزار Instagram Graph API را اضافه کنید:**
    *   در داشبورد برنامه خود، به پایین صفحه بروید و در بخش `Add products to your app`، ابزار `Instagram Graph API` را پیدا کرده و روی `Set Up` کلیک کنید.

پس از انجام این مراحل، برنامه شما در پلتفرم توسعه دهندگان فیسبوک ایجاد شده و ابزار Instagram Graph API به آن اضافه شده است. در مرحله بعد، ما یک توکن دسترسی برای استفاده از API اینستاگرام دریافت خواهیم کرد.

**مرحله ۴: دریافت توکن دسترسی (Access Token)**

1.  **به بخش Graph API Explorer بروید:**
    *   در منوی سمت چپ داشبورد برنامه خود، روی `Tools` کلیک کرده و `Graph API Explorer` را انتخاب کنید.

2.  **برنامه فیسبوک خود را انتخاب کنید:**
    *   در منوی کشویی `Facebook App` در سمت راست، برنامه‌ای که در مرحله قبل ایجاد کردید را انتخاب کنید.

3.  **یک توکن دسترسی کاربر (User Access Token) دریافت کنید:**
    *   در منوی کشویی `User or Page`، `Get User Access Token` را انتخاب کنید.
    *   در پنجره‌ای که باز می‌شود، مطمئن شوید که دسترسی‌های زیر را به برنامه خود می‌دهید:
        *   `instagram_basic`
        *   `instagram_content_publish`
        *   `pages_show_list`
        *   `pages_read_engagement`
    *   روی `Generate Access Token` کلیک کنید.

4.  **توکن دسترسی را کپی کنید:**
    *   توکن دسترسی که در فیلد `Access Token` نمایش داده می‌شود را کپی کنید. این توکن برای استفاده در کد شما لازم است.

پس از انجام این مراحل، شما یک توکن دسترسی برای استفاده از API اینستاگرام در اختیار دارید. لطفاً این توکن را در یک جای امن نگه دارید و آن را با دیگران به اشتراک نگذارید.
